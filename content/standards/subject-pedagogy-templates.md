# VidyaSetu Subject Pedagogy Templates

These templates define the default teaching grammar for each subject family. They are mandatory design guidance, not rigid scripts.

## Science

**Question → Observe → Explain → Do → Connect → Practise → Apply → Revise**

Required characteristics:
- open with an observable phenomenon or familiar question;
- explain cause-and-effect before formal terminology where possible;
- use real objects, diagrams, animation or safe experiments;
- separate observation from inference;
- explicitly address common misconceptions;
- classify practicals as GREEN (learner-safe), AMBER (adult/teacher supervision), or RED (teacher/lab demonstration only);
- include at least one real-life Indian context where natural rather than forced.

Preferred media: concept video, practical/demo video, labelled diagrams, observation table, revision audio.

## Mathematics

**Concrete → Visual → Symbolic → Worked Example → Guided Step → Practise → Apply → Error Check → Revise**

Required characteristics:
- introduce abstractions through quantities, objects, money, measurement, number lines, shapes or situations where appropriate;
- do not reveal complete worked solutions by default when a step-wise interaction is possible;
- include at least one “common mistake” example;
- practice should progress Foundation → Standard → Advanced/Application;
- distinguish procedural fluency from conceptual understanding;
- include mental estimation or reasonableness checks where relevant.

Preferred media: visual model, animated geometry/number line, step-by-step worked example, interactive practice.

## History

**Context → People → Event/Process → Causes → Evidence → Consequences → Different Perspectives → Why It Matters**

Required characteristics:
- use chronology and timelines;
- identify causes and consequences rather than memorising dates alone;
- distinguish primary/secondary evidence when age-appropriate;
- avoid unsupported heroic/villain narratives;
- show geographical context with maps where useful;
- connect historical change to institutions, society, economy or everyday life.

Preferred media: timeline, map, archival/public-domain visual where licensed, narrative audio, source-based questions.

## Geography

**Where → What Pattern → Why There → Process → Human/Environmental Impact → Map → Local Connection → Apply**

Required characteristics:
- maps are central, not decoration;
- teach spatial relationships and scale;
- include process diagrams for physical geography;
- connect national/global ideas to Indian or local examples where appropriate;
- clearly distinguish weather/climate, resource/use, cause/correlation and similar common confusions.

Preferred media: map, terrain/process visual, comparison graphic, data interpretation, field-observation task.

## Civics / Political Science

**Real Problem → Institution → Rule/Right → Process → Responsibility → Trade-off → Citizen Application**

Required characteristics:
- begin with an everyday public-life situation when appropriate;
- explain what an institution does and what it does not do;
- teach rights together with processes and responsibilities;
- use neutral, constitutional and age-appropriate framing;
- separate facts about institutions from contested political opinion.

Preferred media: scenario, process flow, role-play, document excerpt where licensed, application questions.

## English

**Listen → Read → Notice → Understand → Speak → Use → Write → Reflect**

Required characteristics:
- vocabulary in context rather than isolated lists;
- grammar discovered through examples before rule memorisation where possible;
- pronunciation/listening for high-frequency language;
- comprehension must include literal, inferential and application questions;
- speaking/writing tasks should have clear success criteria.

Preferred media: narrated read-along, pronunciation audio, story/dialogue video, vocabulary cards, writing scaffold.

## Hindi and other Indian languages

**सुनें → पढ़ें → अर्थ समझें → बोलें → भाषा का प्रयोग करें → लिखें → पुनरावृत्ति करें**

Required characteristics:
- natural, age-appropriate language;
- साहित्यिक सामग्री में शब्दार्थ, प्रसंग, भाव/विचार और बोध;
- व्याकरण को उदाहरण और प्रयोग से जोड़ना;
- उच्चारण/वाचन support where useful;
- formal academic terminology must remain consistent with the controlled glossary.

Preferred media: narrated read-along, recitation, pronunciation audio, comprehension, writing prompts.

## Computer / Digital Literacy

**Task → Demonstration → Do Along → Explain → Safe Practice → Challenge → Reflect**

Required characteristics:
- screen-recorded or simulated demonstration where appropriate;
- students should perform a task rather than only watch;
- cybersecurity, privacy and digital citizenship included contextually;
- software-specific instructions should be version-aware and avoid unnecessary vendor lock-in.

## Commerce / Economics

**Real Situation → Terms → Model → Worked Document/Data → Decision → Practise → Apply**

Use bills, ledgers, budgets, banking/business situations, tables and charts. Separate accounting procedure from economic reasoning.
