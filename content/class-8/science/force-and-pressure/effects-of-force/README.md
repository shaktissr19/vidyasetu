## Purpose

This pack teaches students to analyse what changes when a force acts. It deliberately follows the Force pack and precedes contact/non-contact forces so the learner first understands the observable effects of interactions.

## VidyaSetu learning journey

- **SEE:** one force, different visible effects.
- **UNDERSTAND:** start/stop motion, speed, direction, shape.
- **DO:** toy-car/soft-ball/sponge observation sequence.
- **PRACTISE:** 12 bilingual questions with reasoning.
- **APPLY:** everyday effect-classification worksheet.
- **REVISE:** bilingual three-minute recap + mastery check.

## Core misconceptions addressed

1. A force always makes an object move from one place to another.
2. Force on a moving object can only stop it.
3. Direction can change only after the object stops.
4. One interaction can have only one effect.
