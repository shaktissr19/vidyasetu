# Content QA Checklist — VS-C8-SCI-FP-PRESSURE-V1

This checklist is mandatory before any resource or assessment in this pack can move from `DRAFT` to `APPROVED` or `PUBLISHED`.

## 1. Science SME review

- [ ] Pressure is consistently treated as force per unit area.
- [ ] Force and pressure are clearly distinguished.
- [ ] Statements about changing area explicitly hold force/load similar where required.
- [ ] `P = F/A` examples are dimensionally correct.
- [ ] `1 Pa = 1 N/m²` is correct and consistently written.
- [ ] Everyday examples do not overstate or oversimplify the physics.
- [ ] The pack does not accidentally teach liquid/atmospheric pressure as part of this concept.
- [ ] All twelve question keys and explanations are independently checked.

## 2. Pedagogy review

- [ ] The hook asks a meaningful question before giving the definition.
- [ ] Concrete/visual reasoning comes before the formula.
- [ ] The learner is asked to predict, observe, explain and apply—not only recall.
- [ ] At least one misconception is directly confronted.
- [ ] Practice progresses from foundation to application/challenge.
- [ ] The final mastery set covers understanding, calculation, experimental reasoning and application.

## 3. Hindi academic-language review

- [ ] Hindi is natural for a Class 8 learner and not a word-for-word machine translation.
- [ ] `बल (Force)`, `दाब (Pressure)`, `क्षेत्रफल (Area)`, `संपर्क क्षेत्रफल (Contact area)`, `पास्कल (Pascal)` are used consistently.
- [ ] Important English terminology is retained on first use where useful for transition between Hindi- and English-medium study.
- [ ] Hindi question meaning is equivalent to the English question.
- [ ] Hindi options do not unintentionally reveal the answer.
- [ ] Numerals, units and symbols render correctly.

## 4. Practical safety review

Safety classification target: **GREEN**.

- [ ] Activity uses only blunt, stable objects.
- [ ] No blade, knife, needle, nail, drawing pin or sharp tool is required.
- [ ] Heavy books are kept close to the work surface.
- [ ] Student is instructed to stop if the setup is unstable.
- [ ] Video shows safe hand placement.
- [ ] Expected result is not presented as something the learner should fabricate.

## 5. Assessment QA

For every question:

- [ ] Public code is unique.
- [ ] Correct answer matches explanation.
- [ ] Exactly one answer is correct for `MCQ_SINGLE`.
- [ ] Numeric answer/tolerance is valid.
- [ ] Difficulty is appropriate.
- [ ] Distractors are plausible but not misleading.
- [ ] No answer depends on wording that exists only in one language.
- [ ] Marks match complexity.
- [ ] No negative marking in this foundational learning pack.

## 6. Media QA

- [ ] 16:9 master, 1080p minimum; 4K production master preferred.
- [ ] One language-light visual master is used where possible.
- [ ] English narration available.
- [ ] Hindi narration available.
- [ ] English subtitles/captions available.
- [ ] Hindi subtitles/captions available.
- [ ] English transcript available.
- [ ] Hindi transcript available.
- [ ] Diagrams have English and Hindi label variants.
- [ ] No long text is permanently burned into shared footage.
- [ ] No copyrighted third-party images/video/music are included without documented rights.

## 7. Accessibility QA

- [ ] Important meaning is not conveyed by colour alone.
- [ ] Text contrast is readable.
- [ ] Diagram alt text exists.
- [ ] Captions include meaningful non-speech audio where relevant.
- [ ] Formula is spoken accessibly in audio, not only displayed visually.
- [ ] Text lesson remains usable without video.
- [ ] Audio revision remains meaningful without seeing the screen.
