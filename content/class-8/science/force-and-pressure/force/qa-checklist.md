# Force Pack QA Checklist

Pack: `VS-C8-SCI-FP-FORCE-V1`  
Status: DRAFT

## Academic accuracy

- [ ] Force is consistently described as a push or pull arising from interaction.
- [ ] Content does not imply that force always produces visible motion.
- [ ] Direction is introduced correctly without prematurely requiring vector calculation.
- [ ] The resting-book example does not imply that a stationary object has no forces.
- [ ] Push/pull examples are age-appropriate and scientifically defensible.
- [ ] Any preview of multiple forces stays conceptual; balanced/unbalanced forces are left for their own concept.

## Hindi academic language

- [ ] `Force` is consistently paired with `बल` on first use.
- [ ] `Push` / `Pull` are consistently rendered as `धक्का` / `खिंचाव`.
- [ ] `Direction` is consistently rendered as `दिशा`.
- [ ] Hindi is conversational and student-friendly without losing scientific meaning.
- [ ] Hindi questions/options/explanations match the intent and difficulty of English versions.

## Practical safety

- [ ] Practical remains GREEN safety level.
- [ ] Only a light toy car/small wheeled object is used.
- [ ] No heavy boxes, running, sharp objects or collision demonstrations are required.
- [ ] Learners are told to record observed results rather than invent expected results.
- [ ] Fair-comparison guidance keeps car, surface and starting point consistent.

## Assessment QA

- [ ] Exactly 12 bilingual questions exist.
- [ ] Every objective answer key points to an existing option.
- [ ] No negative marking.
- [ ] Practice uses questions 001–008.
- [ ] Mastery uses 003, 005, 007, 009, 010, 011 and 012.
- [ ] Question set includes understanding, identification, application, direction, multiple-force reasoning, experimental reasoning and design.
- [ ] Distractors reflect plausible misconceptions rather than trick wording.

## Accessibility and media

- [ ] English and Hindi captions prepared for final video.
- [ ] English and Hindi transcripts prepared.
- [ ] Important meaning is not conveyed by colour alone.
- [ ] Arrow direction is accompanied by text/audio explanation.
- [ ] Embedded video text is minimal so one visual master can support both languages.
- [ ] Offline text remains complete without video/audio.

## Publication gate

Required approvals before `PUBLISHED`:

- [ ] Science SME
- [ ] Hindi academic-language reviewer
- [ ] Assessment QA
- [ ] Safety review
- [ ] Editorial review
- [ ] Final video/audio media attached or explicitly excluded with approved reason
- [ ] Student-facing preview checked in English
- [ ] Student-facing preview checked in Hindi
