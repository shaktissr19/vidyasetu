## Source policy

VidyaSetu stores an original syllabus index and an original instructional concept decomposition. Official/reference sources verify book identity, current session structure, chapter/unit/project names and curriculum policy. Textbook prose is not copied into VidyaSetu learner content.

## Versioning and review rule

1. Chapter/unit titles are factual curriculum identifiers.
2. `topic-index.json` is VidyaSetu's own decomposition and must not be described as verbatim NCERT subheadings.
3. All current indexes must receive subject-SME confirmation before `FINAL` status.
4. If NCERT/CBSE revises the structure, create a new academic-session/version mapping instead of overwriting historical mappings.
5. Reusable VidyaSetu concept IDs should remain stable where the underlying concept remains academically equivalent across versions or boards.
