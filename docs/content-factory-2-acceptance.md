# Content Factory 2.0 — acceptance checklist

- [x] Platform Admin can choose class, board, subject, chapter/topic and language.
- [x] Platform Admin can search enabled governed source connectors.
- [x] External selections enter Source & Licence Review.
- [x] Item-level-review sources require explicit licence verification evidence.
- [x] Required attribution is enforced.
- [x] Unverified items cannot be approved/imported.
- [x] Approved items can be added to canonical Content Library.
- [x] Handoff creates DRAFT content only.
- [x] Board and grade mappings are created.
- [x] Source/licence/attribution metadata is preserved.
- [x] Repeated handoff is idempotent.
- [x] Public/private access-policy mismatch is rejected.
- [x] Admin queue counters/navigation expose pending work.
- [x] CI includes backend/frontend build, migration 049 idempotence and E2E source-to-library certification.
- [x] No automatic publishing path is introduced.
